# Revisa

Revisa todo el proyecto o CWD sin hacer modificaciones. Lo que se quiere es encontrar toda la información disponible sobre un aspecto que el usuario indica en la conversación.

Revisa, por lo menos, esto:

- código
- estructura de la base de datos
- imágenes (si las hay)
- reportes (si los hay)

Y cualquier otra cosa que pueda ayudar a esclarecer la inquietud del usuario. Al final, genera un reporte en pantalla con los descubrimientos.
